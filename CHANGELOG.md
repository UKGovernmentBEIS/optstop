# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [Unreleased]

### Added
- Initial release of optstop package
- Post-hoc optimal stopping functionality
- Live optimal stopping functionality
- Convergence analysis functionality
- CLI interface with three commands
- Comprehensive test suite
- MIT license
- GitHub Actions CI/CD pipeline

### Features
- Adaptive optimal stopping algorithms
- Bayesian and frequentist hybrid methodology
- Parallel processing across groupings
- Comprehensive logging system
- Input validation and error handling
- Reproducibility with random seeds
- Flexible parameter configuration

### Technical
- PyMC integration for hierarchical Bayesian modeling
- ArviZ for MCMC diagnostics
- Pandas for data manipulation
- NumPy for numerical operations
- Command-line interface with argparse
- Comprehensive documentation with examples
